
## Code map (Trail)

The Trail code map of this repository is built in `graft/`. Run it as
`DO_NOT_TRACK=1 GRAFT_NO_STATUSLINE=1 trail <verb>` from the repository root:
`ask "<question in code terms>" [--in <dir>]` (ranked symbols with file:line), `grep "<regex>" [--in <path>]`
(grouped by enclosing symbol), `callers <symbol> [-d N] [--direction out]`, `skeleton <file>` (signatures only),
`map` (orientation).
